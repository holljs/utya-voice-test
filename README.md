# Тестирование голоса Ути (Supertonic 3 TTS) 🦆

Этот репозиторий настроен для генерации озвучки через бесплатные облачные серверы GitHub Actions. Вам **не нужен терминал** и собственный сервер для этого теста!

## Как запустить генерацию прямо в браузере:

1. Перейдите во вкладку **Actions** в верхнем меню вашего репозитория на GitHub.
2. В левой колонке выберите воркфлоу: **Generate Utya Voice Test**.
3. Справа нажмите на серую кнопку **Run workflow** -> и еще раз на зеленую **Run workflow**.
4. Подождите около 1-2 минут (робот GitHub сам установит Supertonic, скачает модель и создаст аудио).
5. Как только появится зеленая галочка успешного выполнения, нажмите на название этого запуска.
6. Прокрутите страницу вниз до раздела **Artifacts** и нажмите на ссылку **utya-voice-audio**, чтобы скачать готовый `.wav` файл к себе на компьютер!
